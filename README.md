# 🛍️ Ozon Price Tracker Telegram Bot

Telegram-бот на **Node.js (чистый JavaScript, без TypeScript)** для постоянного отслеживания цен на товары с маркетплейса **Ozon**.

Бот принимает ссылки на товары Ozon, сохраняет их в локальную базу данных SQLite, периодически проверяет актуальную цену через API и отправляет пользователю подробное уведомление при каждом изменении стоимости (с расчётом разницы в рублях и процентах).

---

## ⚡ Особенности и возможности

- 🚀 **Чистый Node.js (CommonJS, без TypeScript)**: простота запуска, отсутствие этапа компиляции.
- 🔗 **Умный парсер ссылок Ozon**:
  - Распознает ссылки из браузера (`https://www.ozon.ru/product/...`)
  - Распознает короткие ссылки из мобильного приложения (`https://ozon.ru/t/...`, `onelink.me`)
  - Извлекает уникальный артикул (SKU) товара
- 💰 **Отслеживание цен и Ozon Карты**:
  - Фиксирует базовую цену и цену с Ozon Картой
  - Ведёт историю изменений цен
- 🎯 **Желаемая цена (Price Target Alerts)**:
  - Установка желаемого порога стоимости под каждым товаром
  - Мгновенное целевое уведомление при падении цены до желаемой отметки или ниже
- 💡 **Поиск более дешевых аналогов (Smart Analogue & Savings Engine)**:
  - Кнопка «💡 🔍 Найти аналоги дешевле» в карточке любого товара
  - Алгоритмическая очистка названий от рекламного спама (`keywordExtractor`)
  - Поиск предложений с меньшей стоимостью и наглядный расчет экономии в рублях и процентах
  - Взятие любого найденного аналога на отслеживание цен в 1 клик
  - Команда `/analogs <запрос или ссылка>` для быстрого ручного поиска
- 📈 **График динамики цен**:
  - Генерация наглядных графиков цен высокой четкости (QuickChart API) прямо в чат по кнопке
  - Сводка минимума, максимума и общего изменения цены
- ⚙️ **Гибкие настройки уведомлений (/settings)**:
  - Выбор режима: «Только снижение цен» (без уведомлений о подорожании)
  - Учет цены по Ozon Карте
- 🪄 **Интерактивный живой интерфейс и меню на лету**:
  - Индикация активности: постоянный статус `печатает...` и `отправляет фото...` во время парсинга и генерации графиков
  - Каталог товаров `/list` в одном интерактивном сообщении с постраничной навигацией (`⬅️` `➡️`) без засорения чата
  - Мгновенный просмотр карточки товара на лету и кнопка «◀️ Назад к списку»
  - Кнопка «🔄 Обновить цену сейчас» прямо в карточке для точечной проверки стоимости товара в реальном времени
  - Премиальная верстка карточек: бейджи наличия, расчет расстояния до желаемой цены, моноширинный SKU и относительное время обновления
- 🔔 **Уведомления об изменении цен**:
  - Присылает alert при каждом изменении (📉 снижение цены или 📈 повышение)
  - Рассчитывает разницу в рублях и процентах
  - Кнопка для быстрого перехода на сайт Ozon, установки порога и отписки
- ⏰ **Автоматический планировщик (Cron)**:
  - Регулярная фоновая проверка товаров по расписанию (по умолчанию раз в 30 минут)
  - Команда для ручной принудительной проверки в любой момент
- 🗄️ **Полноценная ORM (Sequelize) и поддержка миграций (Umzug)**:
  - Автоматическое применение миграций из `src/database/migrations/` при старте.
  - Строгая фиксация примененных миграций в таблице `SequelizeMeta`.
  - Модели `Product`, `Subscription`, `PriceHistory`, `UserSetting`.
  - Слой Репозиториев (`src/repositories`) изолирует всю работу с базой данных.
  - Хранение даты последнего парсинга (`last_parsed_at`) для каждого товара.
- 🧪 **Встроенный DEMO-режим**:
  - Позволяет моментально протестировать логику бота и получение уведомлений даже без боевого прокси/API Ozon.

## 🛠️ Установка и запуск

### 1. Клонирование и установка зависимостей

Убедитесь, что у вас установлен Node.js версии **18+**:

```bash
cd tg-shopper-bot
npm install
```

### 2. Настройка переменных окружения

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Откройте `.env` и укажите ваш токен:

```env
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ

# Интервал автоматической проверки (cron-выражение)
# По умолчанию: раз в 30 минут
CHECK_INTERVAL_CRON=*/30 * * * *

# Демонстрационный режим для локального тестирования (true / false)
DEMO_MODE=false
```

#### Как получить токен бота:
1. Откройте в Telegram диалог с [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя и юзернейм для вашего бота.
4. Скопируйте полученный HTTP API Token и вставьте в `.env`.

---

### 3. Запуск тестов

Перед запуском бота можно убедиться, что все модули работают корректно:

```bash
npm test
```

---

### 4. Запуск бота

**Обычный запуск:**
```bash
npm start
```

**Режим разработки (автоперезапуск при изменениях в коде):**
```bash
npm run dev
```

## 📱 Как пользоваться ботом

1. Запустите бота командой `/start` в Telegram.
2. Отправьте ссылку на любой товар Ozon, например:
   `https://www.ozon.ru/product/smartfon-apple-iphone-15-128gb-1188735235/`
3. Бот ответит подтверждением:
   ```text
   ✅ Товар добавлен в отслеживание!
   📦 Название: Смартфон Apple iPhone 15
   💰 Текущая цена: 75 000 ₽ (с Ozon Картой: 72 000 ₽)
   🆔 Артикул (SKU): 1188735235
   ```
4. При каждом изменении цены бот автоматически пришлет вам уведомление:
   ```text
   🔔 📉 ЦЕНА СНИЗИЛАСЬ!

   📦 Смартфон Apple iPhone 15
   💰 Было: 75 000 ₽
   🏷 Стало: 69 990 ₽
   📉 Снизилась на 5 010 ₽ (-6.7%)

   [🔗 Открыть на Ozon]  [❌ Перестать следить]
   ```

### Команды бота:
- `/start` — приветствие и главное меню.
- `/list` (или кнопка **«📦 Мои товары»**) — список всех ваших отслеживаемых товаров с кнопками управления («🎯 Задать порог», «📈 График цен», «❌ Отписаться»).
- `/check` (или кнопка **«🔄 Проверить цены»**) — запустить принудительную проверку цен прямо сейчас.
- `/settings` (или кнопка **«⚙️ Настройки»**) — интерактивные тумблеры фильтрации алертов (только снижение цен, учет Ozon Карты).
- `/help` (или кнопка **«ℹ️ Помощь»**) — руководство пользователя.

## ⚙️ Дополнительные настройки в `.env`

- **`PROXY_URL`**: Ozon защищает свои страницы антибот-системами. Если сервер, на котором крутится бот, находится вне РФ или получает ошибку `403`, вы можете указать резидентский или мобильный прокси (например `http://username:password@proxy.example.com:8080`).
- **`CHECK_INTERVAL_CRON`**: расписание проверки цен. Например:
  - `*/10 * * * *` — каждые 10 минут.
  - `0 * * * *` — каждый час.
  - `0 9,15,21 * * *` — трижды в день (в 9:00, 15:00 и 21:00).
- **`DEMO_MODE=true`**: позволяет проверить работу рассылок, кнопок и логики бота с реалистичными эмулированными ценами без внешних запросов к Ozon.
