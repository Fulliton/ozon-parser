# 🤖 Инструкция для Агента: Директория `test`

## Назначение
Директория `test` содержит набор сквозных и модульных тестов для проверки работоспособности всех компонентов Ozon Price Tracker Bot.

## Файлы
- [`testParser.js`](file:///home/fulliton/work/tg-shopper-bot/test/testParser.js):
  - Тестирует валидацию ссылок и парсинг SKU (включая ссылки на реальные товары Ozon).
  - Тестирует очистку строк цен (`cleanPrice`) и форматирование валют.
  - Инициализирует изолированную тестовую базу данных SQLite через Drizzle ORM (`test.db`).
  - Проверяет слой репозиториев: `productRepository`, `subscriptionRepository`, `priceHistoryRepository`.
  - Проверяет корректность сохранения и обновления поля `lastParsedAt`.
  - Проверяет слой сервисов: `productService.trackProduct()`, `subscriptionService`, генерацию сообщений.
  - Автоматически удаляет тестовую БД по завершении тестов.

## Правила для Агента
1. Запуск всех тестов выполняется командой:
   ```bash
   npm test
   ```
2. Тесты не должны требовать подключения к реальной базе данных или внешним сервисам — для работы используется изолированная локальная БД и демо-режим `process.env.DEMO_MODE = 'true'`.
3. После любых изменений в репозиториях, сервисах или парсере обязательно запустите `npm test` и убедитесь в успешном прохождении всех assertions.
