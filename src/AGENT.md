## Назначение
Директория `src` содержит весь исходный код приложения Telegram-бота для мониторинга цен на Ozon.

## Архитектурные слои и правила взаимодействия
Проект построен по слоистой архитектуре с четким разделением ответственности (SoC):

```
Telegram Layer (src/telegram)
        │
        ▼
Service Layer (src/services)
        │
        ▼
Repository Layer (src/repositories)
        │
        ▼
Database / ORM Layer (src/database)
```

### Главные правила:
1. **Строгая инкапсуляция БД**: Никакой код из `src/telegram` или `src/services` не должен выполнять прямые SQL-запросы или обращаться к инстансу базы данных в обход `src/repositories`.
2. **Только через Репозитории**: Любое чтение, сохранение, обновление товаров, подписок или истории цен происходит исключительно через методы репозиториев (`productRepository`, `subscriptionRepository`, `priceHistoryRepository`).
3. **Бизнес-логика в Сервисах**: Обработчики сообщений Telegram (`handlers`) не содержат бизнес-логики; они лишь парсят ввод пользователя, вызывают соответствующий метод сервиса и отправляют ответ.
4. **Управление состоянием парсинга**: При любом парсинге товара (как первичном, так и периодическом) обязательно обновляется поле `lastParsedAt` (`last_parsed_at`) в таблице `products`.

## Структура файлов и поддиректорий
- [`config.js`](file:///home/fulliton/work/tg-shopper-bot/src/config.js): Загрузка переменных окружения (`.env`), настройки cron, proxy, путей к БД.
- [`index.js`](file:///home/fulliton/work/tg-shopper-bot/src/index.js): Главная точка входа. Инициализирует БД, запускает бота и фоновый планировщик, обрабатывает graceful shutdown.
- `database/`: Инициализация SQLite, Sequelize ORM, система миграций Umzug и модели таблиц.
- `repositories/`: Слой репозиториев для абстракции доступа к данным.
- `services/`: Бизнес-логика (парсинг Ozon через Puppeteer, трекинг, уведомления, управление товарами).
- `telegram/`: Код Telegram-бота (Telegraf, обработчики команд, сообщений, инлайн-кнопок, клавиатуры).
- `utils/`: Вспомогательные утилиты (парсинг ссылок и SKU, форматирование валюты и дат).
