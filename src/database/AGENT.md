# 🤖 Инструкция для Агента: Директория `src/database`

## Назначение
Директория `src/database` отвечает за подключение к SQLite через **Sequelize ORM**, управление моделями и запуск миграций схемы через **Umzug**.

## Файлы
- [`index.js`](file:///home/fulliton/work/tg-shopper-bot/src/database/index.js): 
  - Создает и конфигурирует инстанс `Sequelize` (диалект SQLite).
  - Настраивает инструмент миграций `Umzug` с хранилищем примененных миграций `SequelizeStorage` (таблица `SequelizeMeta`).
  - Предоставляет методы `initDb()`, `getSequelize()`, `getMigrator()`, `closeDb()`.
  - При вызове `initDb()` автоматически накатывает все ожидающие миграции из папки `migrations/`.
- `models/`: Модели Sequelize (`Product`, `Subscription`, `PriceHistory`) и их ассоциации.
- `migrations/`: Файлы миграций структуры БД.

## Правила для Агента
1. **Любые изменения схемы БД — только через файлы миграций**: Не изменяйте структуру таблиц вручную, создавайте новый файл миграции в `src/database/migrations/`.
2. **Взаимодействие с данными**: Клиентский код и сервисы обращаются к данным исключительно через слой репозиториев (`src/repositories`), никогда не вызывая методы моделей напрямую из Telegram-хэндлеров.
3. **Хранение даты последнего парсинга**: Таблица `products` всегда содержит поле `last_parsed_at` (маппится на `lastParsedAt` в модели) для отслеживания времени последнего парсинга страницы.
